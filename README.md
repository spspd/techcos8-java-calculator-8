Requirements - Basic
1. 입력한 문자열에서 숫자를 추출하여 더하는 계산기
2. ,과 : 을 구분자로 가지는 문자열 전달시 
   1. 구분자를 기준으로 분리한 각 숫자의 합을 반환
3. 커스텀 구분자
   1. //와 \n 사이에 위치하는 문자를 커스텀 구분자로 사용
4. 잘못된 값 - 오류 발생 - 애플리케이션 종료


Basic Convert
1. 문자열을 입력
2. , : 그리고 // \n 문법을 이용한 커스텀 입력자
   1. 이 경우 "가능하다면" 선 파싱해서 구분자를 추가하는 것이 죻다
   2. Basic:2 에서 만든 코드가 재사용 될 수 있게 할지가 관건
      1. 이 이상은 디자인 패턴 측면에서 고려될 것이라 이번 주차 리뷰에 서술
      2. 이번의 경우 기본적인 테스트 케이스와 구현만으로 시작할 것이므로 직관적으로 진행


진행 과정
1. 문자열 입출력 확인
2. ,를 구분자로 가지는 문자열을 주어진 라이브러리를 사용해서 처리후 계산
3. :를 추가 및 구분자가 긴 문자열 이여도 상관없도록 구현되었는지 확인
   1. 3 분리 
      1. 긴 문자열에서 발생되는 문제점
         1. 스트림처럼 처리중
         2. 문자열에 숫자가 있을경우
         3. 문자열의 시작이 같은데 끝이 다르거나 한쪽이 포함될경우
         4. n개를 "미리" 내다봐야 하고 스킵할수 있어야한다
      2. 선택지
         1. 파싱 처럼 리팩토링 할지
         2. 미리 내다보고 스킵할지
            1. 이 경우 문제점을 한 곳에서 해결할 수 없음

   2. 긴 문자열 확인
   3. 특이사항시 오류나는지 확인
4. // \n 문법을 사용해서 커스텀 입력자 추가 
   1. 오류 검증
